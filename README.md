# RemoteDesk — удалённая работа с компьютером с телефона

Подключайтесь к своему Windows-ноутбуку с телефона: видите рабочий стол вживую,
управляете мышью и клавиатурой, запускаете программы и выполняете команды PowerShell.

- `server/` — сервер на Python, запускается на компьютере.
- `app/` — клиент на Flutter (Android, iOS, Web, Windows, macOS, Linux).

## Возможности

**Экран**
- трансляция рабочего стола (качество: эконом / норма / высокое, несколько мониторов);
- нажатие — клик, долгое нажатие — правый клик, двумя пальцами — масштаб;
- режимы «касание» и «тачпад», перетаскивание, полоса прокрутки справа;
- клавиатура телефона (включая русский), Ctrl/Alt/Shift/Win, Esc, F1–F12, стрелки;
- быстрые сочетания: копировать, вставить, Alt+Tab, закрыть окно, диспетчер задач, громкость.

**Терминал** (главная вкладка — картинка экрана в это время не передаётся)
- простые команды: `opera`, `открыть steam`, `открытые`, `закрыть opera`, `закрыть принудительно 3`,
  `проекты`, `перейти 4`, `vscode 4`, `claude 4`, `спроси <вопрос>`, `unity 9`, `помощь`;
- подсказки при вводе, подробная инструкция (кнопка «?»), список проектов с действиями;
- любые команды PowerShell с сохранением текущей папки (`cd` работает).

## Запуск сервера (на компьютере)

```bat
pip install -r server\requirements.txt
python server\server.py
```

или двойным щелчком по `start-server.bat`.

В окне сервера появятся **адрес**, **порт** (8765) и **ключ доступа**.
Ключ создаётся при первом запуске и хранится в `server/config.json` (этот файл не попадает в git).
Чтобы сменить ключ — удалите `config.json` и перезапустите сервер.

При первом запуске Windows может спросить разрешение для Python в брандмауэре — разрешите.

## Приложение (на телефоне)

```bash
cd app
flutter pub get
flutter build apk --release            # Android
flutter build ios --release            # iPhone (нужен Mac)
flutter build web --release --no-web-resources-cdn -o ../web
```

Если собрать web-версию в папку `web/`, сервер сам раздаёт её:
откройте в браузере телефона `http://<адрес-компьютера>:8765` — ничего устанавливать не нужно.

В приложении введите адрес, порт и ключ из окна сервера.
Без дополнительных программ телефон и компьютер должны быть в одной сети Wi-Fi.
Чтобы подключаться из любого места — смотрите раздел «Работа на расстоянии» ниже.

## Безопасность

Ключ даёт полный контроль над компьютером — не передавайте его посторонним.
Сервер работает по HTTP без шифрования, поэтому используйте его только в своей домашней сети
или через VPN, но не открывайте порт в интернет напрямую.

## Работа на расстоянии (через Tailscale)

| Где вы | Что нужно |
|---|---|
| Телефон и ноутбук в **одной сети Wi-Fi** | ничего, только RemoteDesk |
| Телефон **в другом месте** (мобильный интернет, чужой Wi-Fi) | **Tailscale** на ноутбуке и на телефоне |

Tailscale — бесплатная программа, которая безопасно соединяет ваши устройства через интернет
в одну зашифрованную частную сеть. Порт на роутере открывать не нужно.

1. Скачайте Tailscale на ноутбук и на телефон: **https://tailscale.com/download**
   (Windows, Android — Google Play, iPhone — App Store).
2. Войдите на обоих устройствах **в один и тот же аккаунт**.
3. В Tailscale на ноутбуке посмотрите его адрес — он начинается на `100.` (например, `100.x.x.x`).
4. На телефоне включите Tailscale и в RemoteDesk введите этот адрес вместо обычного,
   порт `8765` и ключ. Или откройте в браузере `http://100.x.x.x:8765`.

Если не подключается — разрешите порт 8765 для сети Tailscale в брандмауэре Windows
(PowerShell от имени администратора):

```powershell
New-NetFirewallRule -DisplayName "RemoteDesk (Tailscale)" -Direction Inbound -Protocol TCP -LocalPort 8765 -InterfaceAlias Tailscale -Action Allow
```

Ноутбук при этом должен быть включён и не спать, а сервер RemoteDesk — запущен.

**Tailscale:** https://tailscale.com/download
