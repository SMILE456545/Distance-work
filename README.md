# RemoteDesk — удалённая работа с компьютером с телефона

Подключайтесь к своему Windows-ноутбуку с телефона: видите рабочий стол вживую,
управляете мышью и клавиатурой, запускаете программы и выполняете команды PowerShell.

- `server/` — сервер на Python, запускается на компьютере.
- `app/` — клиент на Flutter (Android, iOS, Web, Windows, macOS, Linux).

## Возможности

**Экран**
- трансляция рабочего стола (качество: эконом / норма / высокое, несколько мониторов);
- нажатие — клик, долгое нажатие — правый клик, двумя пальцами — масштаб;
- режимы «касание» и «тачпад», перетаскивание, полоса прокрутки справа;
- клавиатура телефона (включая русский), Ctrl/Alt/Shift/Win, Esc, F1–F12, стрелки;
- быстрые сочетания: копировать, вставить, Alt+Tab, закрыть окно, диспетчер задач, громкость.

**Терминал** (главная вкладка — картинка экрана в это время не передаётся)
- простые команды: `opera`, `открыть steam`, `открытые`, `закрыть opera`, `закрыть принудительно 3`,
  `проекты`, `перейти 4`, `vscode 4`, `claude 4`, `спроси <вопрос>`, `unity 9`, `помощь`;
- подсказки при вводе, подробная инструкция (кнопка «?»), список проектов с действиями;
- любые команды PowerShell с сохранением текущей папки (`cd` работает).

## Запуск сервера (на компьютере)

```bat
pip install -r server\requirements.txt
python server\server.py
```

или двойным щелчком по `start-server.bat`.

В окне сервера появятся **адрес**, **порт** (8765) и **ключ доступа**.
Ключ создаётся при первом запуске и хранится в `server/config.json` (этот файл не попадает в git).
Чтобы сменить ключ — удалите строку `"key"` в `config.json` и перезапустите сервер.

При первом запуске Windows может спросить разрешение для Python в брандмауэре — разрешите.

## Приложение (на телефоне)

```bash
cd app
flutter pub get
flutter build apk --release            # Android
flutter build ios --release            # iPhone (нужен Mac)
flutter build web --release --no-web-resources-cdn -o ../web
```

Если собрать web-версию в папку `web/`, сервер сам раздаёт её:
откройте в браузере телефона `http://<адрес-компьютера>:8765` — ничего устанавливать не нужно.

В приложении введите адрес, порт и ключ из окна сервера.
Дома телефон и компьютер в одной сети Wi-Fi. Чтобы подключаться из любого места —
смотрите раздел «Работа из любого места» ниже.

## Быстрое видео экрана

Экран передаётся **видеопотоком H.264 через WebRTC** — как в AnyDesk и Parsec: до 30 кадров в секунду,
трафика в разы меньше, чем у отдельных картинок. Видео идёт **напрямую** между телефоном и ноутбуком
(дома, через Tailscale и через интернет). Мышь и клавиатура едут по тому же соединению — без задержек HTTP.

- Пока открыта вкладка «Терминал», видео на паузе и трафик не тратится.
- Качество (кнопка в панели ☰): Эконом 960 px / 20 к/с, Норма 1366 px / 30 к/с, Высокое 1920 px / 30 к/с.
  Скорость сама подстраивается под интернет.
- Если видео не подключилось (старый браузер, закрыт UDP-порт), приложение само переходит в обычный режим картинками.
- Экран снимается через DirectX (`dxcam`, ~1 мс на кадр), кодирует `libx264` (`aiortc`).

## Безопасность

Ключ даёт полный контроль над компьютером — не передавайте его посторонним.

- Ключ — 16 символов (`XXXX-XXXX-XXXX-XXXX`, ≈80 бит), подобрать его невозможно. Старые 8-значные ключи
  заменяются автоматически. Сменить ключ: удалите строку `"key"` из `server/config.json` и перезапустите сервер.
- После 5 **разных** неверных ключей адрес блокируется на 15 минут, при повторе — на час, 4 часа, сутки.
  Телефон, который просто повторяет старый сохранённый ключ, не блокируется.
- Все входы и неверные ключи записываются в `server/access.log`, новые подключения видны в окне сервера.
- Порт 8765 на роутере не открывается: снаружи доступ только через Tailscale (шифрованный туннель) или по HTTPS через DuckDNS.

## Работа из любого места — через Tailscale (основной способ)

| Где вы | Адрес в приложении |
|---|---|
| Телефон и ноутбук в **одной сети Wi-Fi** | локальный IP ноутбука (`192.168.x.x`), порт `8765` |
| Телефон **где угодно** | IP ноутбука в Tailscale (`100.x.x.x`), порт `8765` |

1. Установите [Tailscale](https://tailscale.com) на ноутбук и телефон и войдите в один аккаунт.
2. В Tailscale на ноутбуке посмотрите его адрес — он начинается на `100.`. Сервер тоже показывает его при запуске.
3. На телефоне включите Tailscale и введите этот адрес и порт `8765` в приложении.

Tailscale работает за любым провайдером, в том числе за CGNAT, и ничего не требует настраивать на роутере.

## Без Tailscale: DuckDNS + HTTPS (только при «белом» IP)

Этот способ работает, **только если провайдер выдал роутеру публичный («белый») IP**.
Проверьте: в настройках роутера (Status → WAN) IP активного подключения **не** должен начинаться
на `100.64.`–`100.127.`, `10.`, `172.16.`–`172.31.` или `192.168.` — иначе это CGNAT, и входящие подключения
из интернета до вас не дойдут. Белый IP обычно можно заказать у провайдера.

Если IP белый:

1. Дважды щёлкните **`setup-internet.bat`**. Он:
   - попросит имя и token с **https://www.duckdns.org** (бесплатное постоянное имя; сервер сам сообщает
     DuckDNS новый IP каждые 5 минут);
   - скачает **Caddy** (caddyserver.com) с модулем DuckDNS — он получает и сам продлевает HTTPS-сертификат;
   - откроет в брандмауэре Windows порты **TCP 8443** и **UDP 8766** (спросит права администратора).
2. В роутере (раздел **Port Forwarding**) добавьте два правила на локальный IP ноутбука.
   В поле WAN Connection выберите **активное** интернет-подключение:

   | Имя | Протокол | Внешний порт | Внутренний порт |
   |---|---|---|---|
   | RemoteDesk-HTTPS | TCP | 8443 | 8443 |
   | RemoteDesk-video | UDP | 8766 | 8766 |

   И закрепите за ноутбуком его локальный IP (**DHCP Binding** / резервирование адреса).
3. Перезапустите сервер. В окне появится строка `https://ИМЯ.duckdns.org:8443` — откройте её на телефоне.
   Проверяйте с мобильного интернета, не из домашнего Wi-Fi.

Чтобы отключить этот способ — очистите `domain` и `duckdns_token` в `server/config.json` и перезапустите сервер.
Порты меняются там же (`https_port`, `rtc_port`).

Ноутбук должен быть включён и не спать, а сервер RemoteDesk — запущен.
