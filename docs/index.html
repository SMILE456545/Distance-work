RemoteDesk Все версии

Ваш компьютер — в телефоне

Экран, терминал и файлы компьютера с телефона — дома и откуда угодно. Скачайте один файл и нажмите на него: программа установится сама и сразу откроется.

Скачать для Windows
Windows 10 и 11 · бесплатно
Программа ставится на компьютер. Откройте эту страницу на компьютере или отправьте себе ссылку.

Три шага

  1. Скачайте и нажмитеЗапустите RemoteDeskSetup.exe. Через несколько секунд программа откроется, на рабочем столе появится ярлык.
  2. Наведите камеруВ окне программы — QR-код. Отсканируйте его телефоном: вход без ввода ключа.
  3. УправляйтеЭкран компьютера, терминал и файлы — в браузере телефона. Ничего ставить на телефон не нужно.

Что умеет

ЭкранВидео экрана со звуком, управление пальцем: касание, прокрутка, перетаскивание, клавиатура.
ТерминалКоманды, запуск программ компьютера, несколько вкладок.
ФайлыОтправить файл с телефона на компьютер или забрать нужный с компьютера.
Не из домаЧерез бесплатный Tailscale — зашифрованно, программа настроит его сама.
РазблокировкаЭкран блокировки Windows открывается с телефона вашим ПИН-кодом.
Обновления в один кликНовая версия приходит в колокольчик в окне программы — нажали «Обновить», и готово.
Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает с программами без платной цифровой подписи. Доступ к компьютеру защищён ключом, который есть только у вас; чтобы выключить доступ, закройте окно программы.
